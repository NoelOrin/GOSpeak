## 技术栈总结

| 层级 | 技术 | 用途 |
|------|------|------|
| **前端框架** | SolidJS | 响应式 UI |
| **路由** | TanStack Router | 客户端路由 |
| **数据获取** | TanStack Query | 服务端状态管理 |
| **UI 库** | TailwindCSS + DaisyUI | 样式系统 |
| **实时通信** | Socket.IO | 信令服务器 |
| **WebRTC** | LiveKit | 音视频通信 |
| **后端语言** | Go | 服务器逻辑 |
| **HTTP 框架** | Gin/Echo | REST API |
| **ORM** | GORM | 数据库操作 |
| **数据库** | SQLite/PostgreSQL/MySQL | 数据持久化 |
| **缓存** | Redis | JWT 黑名单/会话 |
| **认证** | JWT + OAuth2 | 用户认证 |
| **构建工具** | Vite (rolldown) | 前端打包 |
| **包管理** | pnpm | Monorepo 管理 |
| **容器化** | Docker Compose | 部署编排 |
