新暗色

旧暗色的 secondary 是洋红（H 354）、accent 是青（H 181）、destructive 偏粉（H 13），与亮色的橙 / 青柠 / 正红不是同一套色相， 切到深色时整体品牌观感会变。新暗色只改明度与彩度，色相全部沿用亮色。
