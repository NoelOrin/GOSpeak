# 桌面客户端

桌面客户端将同一套界面运行在系统 WebView 中，并补充浏览器不具备的原生能力：关窗进托盘、开机自启、全局快捷键、系统通知、游戏内覆盖层。

## 浏览器与桌面端对比

| 场景 | 浏览器 | 桌面端 |
|------|--------|--------|
| 偶尔进入语音 | 适用 | 无必要 |
| 长时间挂语音 | 需保持标签页 | 关窗进托盘 |
| 游戏中听语音 | 需切换窗口 | 游戏内成员浮窗 |
| 开机自动连接 | 不支持 | 支持 |
| 快捷键闭麦 | 需切回浏览器 | 全局快捷键，游戏内生效 |

## 下载安装

从 [Releases](https://github.com/NoelOrin/GOSpeak/releases) 页面下载 `GOSpeak v<版本>`。
每个版本只有一个 Release，服务端二进制与桌面端安装包都在同一页；正文顶部即桌面端
下载表格，按平台点对应按钮：

| 平台 | 文件 | 安装方式 |
|------|------|----------|
| macOS（Apple Silicon） | `gospeak-desktop-v1.0.0-darwin-arm64.dmg` | 打开并将 GOSpeak 拖入「应用程序」 |
| macOS（Intel） | `gospeak-desktop-v1.0.0-darwin-amd64.dmg` | 同上 |
| Windows | `gospeak-desktop-v1.0.0-windows-amd64.exe` | 双击安装 |
| Linux | `gospeak-desktop-v1.0.0-linux-amd64.deb` | 双击即装；也可用 `.tar.gz` 便携包 |

macOS 提供 Apple Silicon 与 Intel 两个版本，需选择匹配版本。

首次打开若被系统拦截，前往「系统设置 → 隐私与安全性」点击「仍要打开」。安装包未签名。

## 首次启动配置服务器地址

桌面端不预置默认服务器，需手动填写。

启动后停留在登录页，「服务器地址」输入框填入部署地址：

```
https://voice.example.com
```

点击保存，窗口重载一次，之后所有请求发往该服务器。

### 本地代理机制

填写地址后，桌面端在本机 `127.0.0.1` 启动一个代理：

```
桌面窗口 ──► 127.0.0.1:随机端口（本机代理）
                    ├─ 前端页面（内置在客户端里）
                    ├─ /api  ──► 服务器
                    ├─ /ws   ──► 服务器
                    └─ /uploads ──► 服务器
```

该机制的作用：

- 页面与接口同源，无跨域问题
- 后端 HttpOnly Cookie 正常使用，登录态与浏览器一致
- 切换服务器仅修改代理目标，页面无需跳转

服务器地址存储在本地，下次启动自动使用。更换服务器时清除旧站点登录态，避免串号。

## 自定义标题栏

窗口不使用系统标题栏，由应用绘制，但窗口按钮为系统原生：

- macOS：红绿灯，位置与系统一致
- Windows：最小化、最大化、关闭，以及贴靠布局
- Linux：桌面环境按钮

标题栏高度 28px，与网页版顶栏一致。整条栏可拖动窗口，双击按系统习惯缩放。深色模式下按钮与菜单跟随变化。

任务栏、Mission Control、Alt+Tab 始终显示 `GOSpeak`，不随页面变化。

## 游戏内浮窗

游戏内浮窗是一个透明、置顶、不占用任务栏的小窗口，叠加在游戏画面上显示正在说话的成员。

### 启用

设置 → 桌面端 → 启用游戏内覆盖层。默认关闭。

### 显示时机

两种模式：

| 模式 | 行为 |
|------|------|
| 自动 | 检测到前台为全屏应用且已进入语音频道时显示，任一条件不满足时自动隐藏 |
| 手动 | 仅在按下快捷键时切换 |

自动模式适用于游戏场景：进入游戏自动显示，退出自动隐藏。

### 快捷键

可设置两个全局快捷键（在其他应用中也生效）：

- **显示/隐藏浮窗**
- **锁定/解锁浮窗**

锁定状态下浮窗不拦截鼠标，游戏内点击不会误触。解锁后可拖动至任意位置。

### 不透明度

可调节，调低则更透明。

### 是否会重复进房

不会。浮窗不连接服务器，也不建立音频会话，显示内容由主窗口推送。开启浮窗不会导致回声或双重加入。

## 托盘与后台

**关闭窗口不会退出程序**，仅隐藏到托盘。需从托盘菜单点击「退出」才会真正退出。

此为设计行为：游戏语音需在后台保持运行。

托盘菜单：

- 打开 GOSpeak
- 退出

点击 Dock 图标或托盘图标可恢复窗口。

## 开机自启

设置 → 桌面端 → 开机自启。开启后登录系统时自动启动并进入托盘。

## 系统通知

房间邀请与私聊提及通过系统原生通知推送，点击可直接跳转，无需浏览器授权。

## 从源码构建

需要 Go 1.27 或更高版本（MyGo 要求，高于后端的 1.26）。

```bash
pnpm install
cd app/desktop && go mod download && cd ../..

# 开发模式：先启动前端，再启动宿主
pnpm dev:web                                # 前端在 localhost:3000
pnpm --filter @gospeak/desktop-app dev      # 宿主指向上述地址

# 打包
GOSPEAK_TARGET=desktop pnpm --filter @gospeak/web build
rm -rf app/desktop/webui/dist && mkdir -p app/desktop/webui/dist
cp -R app/web/dist/. app/desktop/webui/dist/
pnpm --filter @gospeak/desktop-app build
```

打包时 `cp` 命令不可省略——前端产物需拷入 `app/desktop/webui/dist/`，由 Go 的 `go:embed` 打进二进制。

### 新增原生能力

1. 在 `app/desktop` 中找到对应的 `*.go`，为已绑定的结构体添加方法（第一个参数为 `context.Context`，通过 `mygo.CallerWindow(ctx)` 获取调用窗口）
2. 在 `packages/desktop/src/capabilities/` 添加封装：一个接口、一个原生实现、一个浏览器兜底
3. 运行 `node scripts/check-desktop-commands.mjs` 校验命令名

第三步不可跳过。命令名错误时 MyGo 仅返回 rejected Promise，多数封装会静默吞掉错误，表现为「功能无反应且不报错」。

## 常见问题

**提示「无法连接到服务器」**
先确认浏览器能否打开该地址。浏览器可打开而桌面端不能时，通常为证书问题——自签名证书桌面端不认。

**更换服务器后登录态丢失**
属正常行为。更换服务器会清除 Cookie，需重新登录，用于防止串号。

**浮窗不显示**
检查三项：设置中是否启用、显示策略是否为自动、是否已进入语音频道（自动模式要求已连接）。

**浮窗遮挡游戏操作**
按解锁快捷键后可拖动，或锁定浮窗——锁定状态下鼠标事件穿透。

**macOS 提示「已损坏，无法打开」**
```
xattr -cr /Applications/GOSpeak.app
```
安装包未签名，系统添加了隔离标记，该命令可清除。
