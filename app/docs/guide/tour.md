# 界面导览

本页按界面布局顺序说明各区域的功能。

## 整体布局

```
┌──────────────────────────────────────────────────────────┐
│  标题栏：当前在哪、连接状态、深浅色切换                     │
├────┬─────────────────────┬───────────────────────────────┤
│ 图 │                     │                               │
│ 标 │    频道列表          │        主区域                  │
│ 栏 │    / 聊天列表        │   （语音舞台 / 文字频道 / 管理页）│
│    │                     │                               │
├────┴─────────────────────┼───────────────────────────────┤
│  语音状态条 + 自己的头像/麦克风/扬声器                      │
└──────────────────────────────────────────────────────────┘
```

最左侧为导航图标栏，中间为宽度可拖动调整的列表区，右侧为主区域。底部语音状态条常驻，用于关麦或断开。

## 最左侧图标栏

从上到下依次为：

| 图标 | 功能 |
|------|------|
| 首页 | 查看所有公开域并加入 |
| 聊天 | 私聊列表 |
| 分享链接 | 生成邀请链接 |
| 设置 | 音频设备、主题、账号、桌面端选项 |
| 管理 | 仅管理员可见，管理用户、域、角色、存储等 |
| 分隔线以下 | 已加入的每个域各一个图标，点击切换 |

域图标需**双击**进入，以避免误触切域导致语音重连。

## 中间列表区

列表内容取决于当前位置：

- 在某个域内 → 显示该域的语音频道与文字频道，语音在上、文字在下
- 在聊天页 → 显示私聊会话
- 在首页 → 显示可加入的域

列表与主区域之间的竖线可拖动，调宽后宽度会被记住。

## 主区域

### 语音频道

成员以方块阵列显示。正在说话的成员头像外显示绿色光环。

底部控制条（或快捷键）：

| 操作 | 方式 |
|------|------|
| 开/关麦克风 | 点击左下角麦克风图标，或按 `M` |
| 关闭所有声音 | 点击扬声器图标 |
| 单独调节某人音量 | 点击成员，在弹出卡片中拖动音量条 |
| 踢人 / 禁言 | 点击成员卡片，需相应权限 |
| 断开 | 点击语音状态条右侧的红色挂断按钮 |

> 「静音」与「禁言」不同。静音只影响本地听到的声音，不影响他人；禁言由服务端强制，被禁言者无法发声但仍可收听。

### 文字频道

标准聊天界面，支持：

- 发送消息（回车）
- 悬停消息 → 回复、添加表情反应
- 悬停自己的消息 → 编辑、删除
- 管理员删除他人消息（需相应权限）
- 消息搜索

右侧成员栏可收起，为消息区留出空间。

### 管理页

入口仅对持有相应权限的用户可见。包含用户、角色、域、禁言、存储、邮件、OAuth、SFU、服务监控等板块，各板块独立鉴权——可见「用户管理」不代表可见「存储」。

## 顶栏

顶栏显示三项信息：

- **左侧**：GOSpeak 字样
- **中间**：当前位置（频道或页面名）
- **右侧**：连接状态圆点与深浅色切换

连接状态有三种：已连接（绿）、连接中（黄，闪烁）、已断开（红）。断开时点击可重连。

## 底部状态条

进入语音频道后，该状态条常驻，切换页面时不消失——语音连接保持。点击状态条主体可跳回当前频道，右侧为挂断按钮。

## 常见疑问

**切换页面后为何仍能听到声音？**
语音会话挂在布局层，不随页面卸载，此为设计行为。

**域图标为何需双击？**
单击为选中，双击为进入，避免误触切域导致重连。

**成员栏为何有时不显示？**
窄屏（宽度小于 768px）切换为移动布局，成员栏变为底部标签页之一。

**更换音频设备时如何处理？**
插入或拔出耳机时界面弹窗询问是否切换，不会自动切换。

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `M` | 开/关麦克风（输入框聚焦时不生效） |

桌面端另有全局快捷键（在其他应用中也生效），在「设置 → 桌面端」中配置。
