# 界面导览

第一次进来容易迷路。这篇按你实际会看到的顺序，把每个区域讲一遍。

## 整体长这样

```
┌──────────────────────────────────────────────────────────┐
│  标题栏：当前在哪、连接状态、深浅色切换                     │
├────┬─────────────────────┬───────────────────────────────┤
│ 图 │                     │                               │
│ 标 │    频道列表          │        主区域                  │
│ 栏 │    / 聊天列表        │   （语音舞台 / 文字频道 / 管理页）│
│    │                     │                               │
├────┴─────────────────────┼───────────────────────────────┤
│  语音状态条 + 自己的头像/麦克风/扬声器                      │
└──────────────────────────────────────────────────────────┘
```

最左边那一竖条是导航，中间是可拖宽的列表，右边是主区域。底部那条一直在，随时能关麦或断开。

## 最左侧图标栏

从上到下依次是：

| 图标 | 干什么 |
|------|--------|
| 首页 | 看所有公开域，找地方加 |
| 聊天 | 私聊列表 |
| 分享链接 | 生成邀请别人进来的链接 |
| 设置 | 音频设备、主题、账号、桌面端选项 |
| 管理 | 只有管理员看得到，管用户、域、角色、存储等 |
| 分隔线以下 | 你加入的每个域一个图标，点一下切过去 |

域图标需要**双击**进入——这是为了防止误触切域，切域会重连语音。

## 中间的列表区

列表显示什么取决于你当前在哪：

- 在某个域里 → 显示这个域的语音频道和文字频道，上面是语音、下面是文字
- 在聊天页 → 显示你的私聊会话
- 在首页 → 显示可加入的域

列表和主区域之间的竖线可以拖动，调宽后宽度会记住。

## 主区域

### 语音频道

进去以后看到的是成员方块阵列。谁在说话，头像外面会有绿色光环。

底部控制条（或用快捷键）：

| 操作 | 怎么做 |
|------|--------|
| 开/关麦克风 | 点左下角的麦克风图标，或直接按 `M` |
| 关掉所有人的声音 | 点扬声器图标 |
| 单独调某人音量 | 点成员，在弹出卡片里拖音量条 |
| 踢人 / 禁言 | 点成员卡片，需要对应权限 |
| 断开 | 点语音状态条右边的红色挂断按钮 |

> 「静音」和「禁言」不是一回事。静音只影响你自己听到的声音，别人不受影响；禁言是服务端强制的，被禁言的人发不出声音，但还能听。

### 文字频道

普通聊天界面，支持：

- 发消息（回车）
- 悬停消息 → 回复、加表情反应
- 悬停自己的消息 → 编辑、删除
- 管理员可以删别人的消息（需要权限）
- 消息搜索

右侧成员栏可以收起，把空间留给消息。

### 管理页

只有持有相应权限才看得到入口。里面分用户、角色、域、禁言、存储、邮件、OAuth、SFU、服务监控几个板块，每个板块独立鉴权——你能看到「用户管理」不代表你能看到「存储」。

## 顶栏

顶栏显示三样东西：

- **左边**：GOSpeak 字样
- **中间**：你现在在哪（当前频道或页面名）
- **右边**：连接状态圆点 + 深浅色切换

连接状态有三个值：已连接（绿）、连接中（黄，会闪）、已断开（红）。断开时点一下会重连。

## 底部状态条

进过语音频道后，这条会一直在，即使你切到别的页面也不消失——语音连接没断。

点状态条主体可以跳回当前频道。右边是挂断按钮。

## 几个容易困惑的点

**为什么切到别的页面还能听到声音？**
语音会话挂在布局层，不跟着页面卸载。这是设计如此，不是 bug。

**为什么域图标要双击？**
单击是选中，双击才是进入。避免手滑切域导致重连。

**为什么成员栏有时候不显示？**
窄屏（宽度小于 768px）会切成移动布局，成员变成底部标签页之一。

**换设备了怎么办？**
插入或拔出耳机时，界面会弹窗问你要不要切到新设备，不会偷偷切。

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `M` | 开/关麦克风（不在输入框里时生效） |

桌面端还有全局快捷键（切到别的应用也有效），在「设置 → 桌面端」里配。
