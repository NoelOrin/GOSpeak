# 常见问题

## 部署相关

### 服务器要什么配置？

| 人数 | 配置 | 备注 |
|------|------|------|
| 10 人内 | 1 核 1G | 能跑，不宽裕 |
| 几十人 | 2 核 4G | 推荐起点 |
| 上百人 | 4 核 8G+ | LiveKit 最好单独一台 |

真正吃资源的是音频转发和带宽，不是 CPU。每个说话的人约 40-60 kbps 上行，听的人按人数累加。

### 一定要用 Docker 吗？

不用。可以只跑一个二进制文件，前端已经打进去了。但那样得自己另外部署 LiveKit。详见 [单二进制部署](/deploy/binary)。

### 没有域名能用吗？

能，但语音用不了。浏览器只在 HTTPS 或 localhost 下给麦克风权限。

内网测试可以用 `http://localhost`，或者用自签名证书。给外部人用必须有正经证书。

### 必须开哪些端口？

最少这四个，少一个语音就不通：

- `7880/tcp` 信令
- `7881/tcp` 媒体
- `7882/udp` 媒体
- `3478/udp` TURN

再加 `80/443` 给网页。云服务器记得系统防火墙和云厂商安全组都要开。

### 能部署到群晖 / 群晖 NAS 吗？

能，用 Docker。ARM 机型拉 `linux/arm64` 镜像。注意 NAS 的 CPU 比较弱，人多会卡。

### 支持 ARM 吗？

支持。发布镜像有 `linux/amd64` 和 `linux/arm64`，二进制也有 arm64 和 armv7 版本。

## 使用相关

### 用户数有上限吗？

软件层面没有硬限制。实际上限取决于：

- 数据库：SQLite 大约 50 人以内同时在线比较稳
- 带宽：这才是真正的瓶颈
- LiveKit 所在服务器性能

### 能同时进多个语音频道吗？

不能。一个人同一时间只在一个语音频道里。切频道会自动退出上一个。

### 关掉浏览器语音会断吗？

会。浏览器方案下关标签页就断了。

想让它一直挂着用[桌面客户端](/guide/desktop)——关窗只是藏到托盘，语音连接不断。

### 支持视频吗？

数据模型里有 `audioOnly` 字段，默认只开音频。当前版本主要面向游戏语音，视频不是重点。

### 消息能编辑和删除吗？

能。自己的消息随时能编辑删除，别人的需要 `message:delete_others` 权限。

### 能私聊吗？

能。左侧栏「聊天」里就是私聊会话。

### 数据存在哪？

- 用户、消息、房间 → 数据库（SQLite 文件或 PostgreSQL）
- 头像、附件 → 你配的存储（本机目录或对象存储）
- 语音 → 不存储，实时转发

没有任何数据发到第三方，除非你用了 LiveKit Cloud。

## 语音相关

### 听不到声音怎么办？

按顺序查：

1. 浏览器有没有给麦克风权限
2. 服务器 `7881/tcp`、`7882/udp`、`3478/udp` 开了没
3. 页面是 HTTPS 的话，`LIVEKIT_HOST` 是不是 `wss://`
4. LiveKit 容器活着没：`docker compose ps livekit`

详细步骤见[故障排查](/deploy/troubleshooting)。

### 有回声？

外放 + 麦克风会互相拾音，戴耳机。

### 声音断断续续？

带宽不够或 UDP 丢包。看服务器出网带宽是不是打满了。

### 能调某个人的音量吗？

能。在成员列表里点那个人，弹出卡片里有音量条，按成员独立调节。

### 「静音」和「禁言」什么区别？

- **静音**：只影响你自己听到的声音，别人不受影响
- **禁言**：服务端强制，被禁言的人发不出声音，但还能听

## 配置相关

### LiveKit 需要 Redis 吗？

不需要。单节点 LiveKit 不依赖 Redis。多节点集群才需要，那个得自己按 LiveKit 文档配，不在 GOSpeak 的部署清单里。

### 需要外部的 NATS 吗？

不需要，也不能配。NATS 是进程内嵌的，负责内部事件、JWT 黑名单、密钥轮换、异步任务。

### 怎么改端口？

```ini
SERVER_PORT=9000
```

Docker 部署的话还要改 compose 里的端口映射。

### 改完配置不生效？

Docker 部署要用 `docker compose up -d`，不能用 `restart`——后者不重新读环境变量。

后台改过的配置（SFU、存储、邮件、OAuth）存在数据库里，优先级高于环境变量。

### 能改界面文字吗？

前端代码在 `app/web`，改完重新构建。没有内置的多语言切换。

## 账号相关

### 默认管理员是什么？

`admin` / `admin123`，首次启动时如果库里没有 `admin` 就自动创建。**上公网前必须改掉。**

### 忘记管理员密码怎么办？

进数据库直接改，或者删库重来（会丢数据）。

### 怎么封禁用户？

把用户的角色改成 `ban`，中间件会拦截所有受保护接口。

### 访客和注册用户什么区别？

访客不用注册，通过邀请码进来，能做什么由域的三个开关决定。有独立的封禁列表。

## 升级相关

### 怎么升级？

```bash
git pull
cd deploy
docker compose up -d --build
```

数据库表结构自动迁移。升级前备份。

### 升级会丢数据吗？

不会。数据在数据卷里，重建容器不影响。

但如果你用了 `docker compose down -v`，`-v` 会删数据卷——那是不可逆的。

### 能从旧版本直接跳到最新版吗？

跨很多版本的话建议先备份再升，中途可能有不兼容的迁移。单个版本之间一般没问题。
